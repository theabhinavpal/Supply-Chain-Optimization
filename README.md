# Supply Chain Optimization using Excel & R
### End-to-End Supply Chain Analytics & Optimization Project

A production-style supply chain analytics project covering data cleaning, exploratory analysis,
inventory optimization, demand forecasting, supplier and transportation analysis, and an executive
Excel dashboard — built on a realistic ~12,000-row order dataset with genuine seasonality, Pareto
customer/product concentration, and category-level margin differences baked in (not random noise).

Every number in `reports/Business_Insights.md` was produced by actually running the R scripts in
this repo against the data in `dataset/`, including a real SQLite database that the cleaning script
builds and query-tests. Nothing here is hand-typed filler.

---

## What's in this repo

| Folder | Contents |
|---|---|
| `dataset/` | Raw export (with realistic data-quality issues), the cleaned analysis-ready CSV, and a SQLite DB |
| `r/` | 10 numbered R scripts (load → clean → EDA → inventory → forecasting → supplier → transportation → cost optimization → visualizations → insights) + shared `utils.R` |
| `excel/` | 4 Excel workbooks (Executive Dashboard, Pivot-style summaries, KPI Scorecard, Operational Reports) — every metric is a live formula, not a hardcoded number |
| `images/charts/` | 10 PNG charts generated by the R scripts |
| `reports/` | Business questions, insights, KPI report, data dictionary, forecast/statistical writeups, and an interview-prep guide |

## Quick start

```bash
# R dependencies (Ubuntu/Debian — all available via apt, no CRAN needed)
sudo apt install r-base-core r-cran-tidyverse r-cran-forecast r-cran-lubridate \
  r-cran-openxlsx r-cran-readxl r-cran-reshape2 r-cran-stringr r-cran-scales \
  r-cran-plotly r-cran-caret r-cran-rsqlite

cd r
Rscript 01_data_loading.R
Rscript 02_data_cleaning.R      # writes dataset/Supply_Chain_Data_Clean.csv + dataset/supply_chain.db
Rscript 03_eda.R
Rscript 04_inventory_analysis.R
Rscript 05_demand_forecasting.R
Rscript 06_supplier_analysis.R
Rscript 07_transportation_analysis.R
Rscript 08_cost_optimization.R
Rscript 09_visualizations.R     # writes images/charts/*.png
Rscript 10_business_insights.R  # prints the consolidated insight summary
```

Each script can also be run independently once `dataset/Supply_Chain_Data_Clean.csv` exists.

## The headline numbers

- **$9,951,737** in revenue across **12,000 orders**, at a **16.7%** blended margin
- **30.8%** of individual orders are unprofitable (**$148,394** in aggregate losses) — concentrated in
  Electronics (the only category with a negative overall margin, at **-21.0%**) and premium (Air/Parcel) freight
- **December** runs **+33.5%** above baseline demand; **February** runs **-40.7%** below it — a real,
  repeatable seasonal pattern, not noise
- Supplier on-time delivery rate correlates with customer satisfaction at **r = 0.82** (p < 0.001)
- Singapore's warehouse peaks at **135%** of rated capacity during the Nov/Dec surge
- A simple 3-month moving average currently **outperforms ETS and ARIMA** on this data (MAPE 15.2% vs
  25.8%/26.1%) because 21 months of history isn't enough for automatic seasonal model selection to lock on —
  a genuine, honestly-reported finding, not a forced "advanced model wins" narrative

one-page version.

## Data note

This is a synthetically generated dataset built to mirror real supply-chain statistical patterns
(seasonality by category, Pareto-distributed customer and product concentration, category-specific
margin bands, mode-dependent freight economics, supplier reliability profiles). It is not real
company data. Every insight in this repo is a genuine output of the analysis scripts run against
this data — the generation process is documented in `reports/Data_Dictionary.md`.
